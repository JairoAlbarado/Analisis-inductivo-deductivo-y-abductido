# Analisis-inductivo-deductivo-y-abductido
## 1. Análisis inductivo

El análisis inductivo consiste en leer y analizar información para identificar patrones entre diferentes casos, ideas u observaciones. A partir de esos patrones puedo construir una conclusión más general.

Ejemplo: Si al leer un artículo encuentro varias observaciones que presentan características similares, podría relacionarlas e identificar un patrón. Después podría formular una conclusión general sobre lo que he observado.

Sin embargo, encontrar un patrón no significa que mi conclusión sea necesariamente verdadera. Necesitaría más información para evaluar si esa conclusión está respaldada y hasta dónde puedo generalizarla.

## 2. Análisis deductivo

El razonamiento deductivo consiste en partir de principios, reglas o premisas generales para obtener una conclusión sobre un caso particular.

Ejemplo: Al leer un artículo, podría identificar una afirmación general y analizar cómo se aplica a una situación específica. Si las premisas son verdaderas y el razonamiento es válido, la conclusión se sigue necesariamente de ellas.

No se debe confundir aplicar una regla con comprobar si esa regla es verdadera. Si encuentro una afirmación en un artículo, no debería asumir automáticamente que es correcta solo porque está escrita allí. Para evaluar las premisas que utilizó, tendría que examinar la información que las respalda.

## 3. Análisis abductivo

El razonamiento abductivo consiste en observar un hecho o un problema y proponer una hipótesis que pueda explicar por qué ocurrió.

Ejemplo: Al leer un artículo, podría encontrar una situación que necesita una explicación y plantear una posible causa. Después tendría que buscar información y evaluar si la hipótesis es razonable o si debo descartarla.

Una hipótesis no se convierte en verdadera simplemente porque parezca lógica. Debo evaluarla con la evidencia disponible y considerar otras explicaciones posibles.

## 4. Diferencias que entendí entre los tres razonamientos

* **Inductivo:** parto de varios casos u observaciones, identifico patrones y construyo una conclusión más general.
* **Deductivo:** leo premisas generales y las aplico a un caso particular para obtener una conclusión.
* **Abductivo:** observo un hecho o problema y propongo una posible explicación que después debo evaluar.

## 5. Cómo utilizaría los razonamientos en una investigación

Podría utilizar estos tres razonamientos durante una investigación, dependiendo de lo que encuentre y de lo que necesite comprender.

* **Inductivo:** al leer uno o varios artículos, identificaría ideas, observaciones o casos que se repiten. A partir de esos patrones, intentaría construir una conclusión general y buscaría más información para evaluar si está respaldada.
* **Deductivo:** si encuentro principios o afirmaciones generales que tengo motivos para aceptar, analizaría cómo se aplican a un caso particular. Después comprobaría si mi conclusión se deriva correctamente de las premisas que estoy utilizando.
* **Abductivo:** si encuentro un problema o una situación que necesita explicación, formularía una hipótesis que pudiera explicar lo ocurrido. Luego buscaría información y evidencia para evaluar si esa explicación es razonable o si debería considerar otras posibilidades.

Entiendo que puedo utilizar más de un razonamiento durante una misma investigación. Por ejemplo, podría identificar un patrón mediante el razonamiento inductivo y después plantear una posible explicación mediante el abductivo.

Mi objetivo sería no quedarme únicamente con lo que dice un artículo, sino analizar la información, construir mis propias conclusiones y comprobar si la evidencia las respalda.
